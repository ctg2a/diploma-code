# Модификация метода муравьиных колоний для многокритериальной оптимизации
## Стек:
* C#
* .NET Framework
* Основные библиотеки: LINQ, System.Collections.Generic
## Основные цели:
Целью данного проекта была модификация метода муравьиных колоний (МАМК) для решения задачи многокритериальной оптимизации, применяя его к задаче оптимизации инвестиционного портфеля. В рамках работы была реализована недоминируемая сортировка, которая позволила улучшить эффективность алгоритма в условиях многокритериальных задач.

В рамках проекта была проведена разработка нового подхода к оптимизации, учитывающего несколько конфликтующих критериев, таких как доходность и риск инвестиционного портфеля. Модификация алгоритма позволила решить проблему поиска оптимального решения, принимая во внимание различные предпочтения инвесторов.

## Данные:
Для тестирования алгоритма использовались реальные финансовые данные о доходности различных активов. Задача заключалась в том, чтобы сформировать инвестиционный портфель, который оптимально сочетает высокую доходность и низкий риск.

## Этапы работы:
### Разработка модификации метода муравьиных колоний:
Основное внимание было уделено улучшению эффективности положительного и отрицательного взаимодействия муравьев для поиска оптимального решения. Модификация алгоритма включала адаптацию правил взаимодействия муравьев с учетом множественных критериев.

### Реализация недоминируемой сортировки:
Для решения задачи многокритериальной оптимизации была внедрена недоминируемая сортировка, которая позволяла учитывать несколько критериев одновременно и находить множество оптимальных решений.

### Сравнение с точным решением:
Для оценки эффективности работы модифицированного алгоритма был проведен сравнительный анализ с задачами с известными точными решениями. Результаты показали, что модифицированный алгоритм позволяет достигать хороших приближенных решений за меньшее время.

### Оптимизация инвестиционного портфеля:
Алгоритм был применен для оптимизации инвестиционного портфеля, где каждый актив имел свои показатели риска и доходности. Задача заключалась в том, чтобы найти оптимальное распределение средств между активами с учетом разных рисков и доходностей.


## Результаты:
* Разработан модифицированный алгоритм муравьиных колоний для многокритериальной оптимизации.
* Внедрена недоминируемая сортировка, что позволило решать задачу с несколькими критериями одновременно.
* Проведен сравнительный анализ с точным решением, который показал, что алгоритм может быть использован для решения практических задач в области финансов.
* Оптимизирован инвестиционный портфель, учитывающий риски и доходности активов.
